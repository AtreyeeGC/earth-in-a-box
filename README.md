# Earth in a Box 🌍

A computational planetary climate and habitability simulator.

## Project Goal

Earth in a Box is an educational scientific-computing project that explores how planetary properties such as orbital distance, atmospheric composition, albedo, and surface conditions influence climate and habitability.

## Current Status

🚧 Early development

The first milestone is a simplified planetary energy-balance model capable of estimating a planet's effective temperature.
